# Internal: escalating repeated missed bins (Bury)

> Fictional test document. It is not a real Bury Council procedure. It exists so that a leak between councils can be detected: the code CANARY-BURY-INT-326c98 must never appear in any answer, search result or log for the other council.

## Purpose
How the Waste team escalates repeated missed bins. Staff-only note; residents never see this text.

## When to escalate
An address or street with a second missed collection of the same bin (Grey, Blue, Green or Brown) within four weeks is escalated, even if the first report was closed. Look for earlier `BRY/` references at the same location before closing a new one.

## Steps
1. Link the new request to the earlier `BRY/` reference and set the status to in-progress.
2. Check the in-cab system for the crew's note for that day (no access, bin not presented, contaminated bin).
3. If the miss was ours, arrange a return collection within two working days and set the request to scheduled.
4. A third miss in the same four weeks is passed to the Waste operations lead for a round review.

## Tracking code
Add CANARY-BURY-INT-326c98 to the internal note of every escalated request so escalations can be counted in reporting.
