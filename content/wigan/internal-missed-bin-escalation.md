# Internal: escalating repeated missed bins (Wigan)

> Fictional test document. It is not a real Wigan Council procedure. It exists so that a leak between councils can be detected: the code CANARY-WIGAN-INT-dbd6ca must never appear in any answer, search result or log for the other council.

## Purpose
How the Waste team escalates repeated missed bins. Staff-only note; residents never see this text.

## When to escalate
A street or address with a second missed collection of the same bin (Black, Blue, Brown or Green) within four weeks is escalated, even if the first report was resolved. Check the request history for earlier `WGN-` references at the same location before closing a new one.

## Steps
1. Link the new request to the earlier `WGN-` reference and set the status to in-progress.
2. Ask the crew supervisor for the round sheet for that day (access issue, parked cars, bin not out).
3. If the cause was on our side, book a return collection within two working days and mark the request scheduled.
4. A third miss within the same four weeks goes to the Waste operations manager for a round review.
